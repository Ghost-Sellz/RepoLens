# Privacy

RepoLens is designed with privacy as a core principle.

## Local-First

All repository analysis runs entirely on your local machine. No repository contents, source code, or file data is transmitted to any external server.

## No External APIs

By default, RepoLens makes zero network requests. All detection is performed through local file scanning and pattern matching.

## GitHub URL Support

When analyzing a GitHub URL, RepoLens clones the repository to a temporary local directory, analyzes it, and then cleans up the temporary files. The clone uses Git directly (no API calls required for public repositories).

## Optional GitHub Token

For private repositories, you can set the `GITHUB_TOKEN` environment variable. This token is used only for git clone operations and is never logged or transmitted elsewhere.

```
export GITHUB_TOKEN=ghp_xxxxx
repolens https://github.com/your-org/private-repo
```

## Web Dashboard

The web dashboard reads reports generated by the CLI. It does not upload any data. Reports can be loaded locally.

## Data Collection

RepoLens collects no telemetry, analytics, or usage data.

## Open Source

RepoLens is fully open source. You can audit the code to verify these privacy claims.
